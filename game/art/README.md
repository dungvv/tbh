# Art

Sprites are drawn as character grids in `../art.gd` (one char = one pixel). Palette: Sweetie 16 by GrafxKid (CC0) plus two wood tones. All grids are original to this project.

To replace a sprite, put a PNG here named after its key in `art.gd` (`hero_walk_a.png`, `boss.png`, `icon_ring.png`, ...). Keep the same size, transparent background, and import with Filter: Nearest. Item icons should stay greyscale: the game tints them by tier.

Record the source and license of every PNG you add below.
